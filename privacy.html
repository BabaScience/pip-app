Pip – Privacy Policy

Last updated: November 2, 2026

What Pip is

Pip is a personal assistant used only by its owner, on the owner's own Mac. It is not offered to the public.

Data Pip accesses

With the owner's explicit consent through Google sign-in, Pip uses the YouTube Data API and YouTube Analytics API to access data of the owner's own YouTube channel:

  • channel information and the list of videos;
  • video statistics, analytics and revenue reports (read-only YouTube scopes);
  • uploading videos to the channel, only when the owner asks for it.

How data is used and stored

This data stays on the owner's Mac. It is not sold, not shared with any third party, and not used for advertising. It is used only to give the owner information about, and help manage, their own channel.

Google API Services User Data Policy

Pip's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke Pip's access at any time at https://myaccount.google.com/permissions.
